# DEPLOYMENT GUIDE

## Requirements
- Node.js 20+
- Environment variables for Supabase and any AI provider configuration
- Production-ready secrets management

## Build and deploy
1. Run npm install.
2. Run npm run lint.
3. Run npm run typecheck.
4. Run npm run test -- --run.
5. Run npm run build.
6. Deploy the production build to Vercel or another compatible host.
